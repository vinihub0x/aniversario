🎨 CUSTOMIZAÇÃO RÁPIDA (5 MINUTOS)

1️⃣ MUDAR NOME
   Arquivo: index.html, linha ~27
   Encontre: <h1 class="hero-title">NICOLY</h1>
   Mude: <h1 class="hero-title">SEU NOME</h1>

2️⃣ MUDAR DATA
   Arquivo: script.js, linha ~50
   Encontre: const dataInicio = new Date(2026, 1, 13, 0, 0, 0);
   Formato: new Date(AAAA, MM-1, DD, HH, MM, SS)
   
   Exemplo para 14/02/2023, 15:30:00:
   const dataInicio = new Date(2023, 1, 14, 15, 30, 0);

3️⃣ ADICIONAR FOTOS
   1. Coloque suas fotos em pasta "fotos/"
   2. Abra script.js
   3. Procure "const carouselData"
   4. Atualize os caminhos e textos

4️⃣ MUDAR CORES (Opcional)
   Arquivo: style.css, linha ~2-9
   Edite as variáveis no :root
   
   Exemplo roxo → vermelho:
   --color-secondary: #ff1744;

🆘 PROBLEMAS COMUNS & SOLUÇÕES

❌ Fotos não aparecem
✅ Coloque-as em pasta "fotos/" com nomes como foto1.jpeg
✅ Atualize os caminhos em script.js

❌ Contador não aparece
✅ Abra console (F12) e procure erros
✅ Verifique data em script.js

❌ Página carrega lenta
✅ Comprima as imagens (use TinyPNG)
✅ Remova imagens desnecessárias

❌ Modal não funciona
✅ Verifique se IDs estão corretos
✅ Abra console para erros

❌ Cores estão erradas
✅ Limpe cache (Ctrl+Shift+Delete)
✅ Verifique format hex (#RRGGBB)
